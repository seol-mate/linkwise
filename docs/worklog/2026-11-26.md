# 2026-11-26 작업 기록

## 1. 테스트 기본 환경을 node로 변경 (`6504216`)

### 배경
- 11-25 기록의 남은 작업 4번. Vitest 기본 환경이 `jsdom`이라 테스트 파일마다 jsdom을 새로 만들었고, 전체 테스트가 약 65초 걸리고 가끔 워커 타임아웃이 났다.
- DOM을 쓰는 테스트는 하나도 없었다.

### 변경
- `vitest.config.mts`: `environment: "jsdom"` → `"node"`.
- 앞으로 DOM이 필요한 테스트 파일만 맨 위에 `// @vitest-environment jsdom`을 붙인다(설정 파일 주석에 적어 둠). 지금은 그런 파일이 없다.

### 결과
- 커밋 당시 측정: 전체 테스트 약 12~15초.
- 11-27 재측정: 13개 파일, 183개 테스트 모두 통과. Vitest 기준 약 25초, `npm run test:run` 전체로는 약 48초. 대부분이 import 시간(91%)이다. WSL의 `/mnt/c` 파일 접근 속도 때문에 실행할 때마다 편차가 큰 것으로 보인다(추정).

### 메모
- 5개 파일(`ai`, `stale`, `safe-fetch`, `login-error`, `users`)에 남아 있는 `// @vitest-environment node` docblock은 이제 기본값과 같아서 없어도 된다. 동작에는 영향이 없어 그대로 두었다.
